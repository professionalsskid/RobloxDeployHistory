## Data Sources

This project fetches version information from the following Roblox API endpoints:

### Deploy History
- https://setup.rbxcdn.com/DeployHistory.txt
- https://setup.rbxcdn.com/Mac/DeployHistory.txt

### Client Versions - LIVE Channel
- https://clientsettings.roblox.com/v2/client-version/WindowsPlayer/channel/LIVE
- https://clientsettings.roblox.com/v2/client-version/WindowsStudio64/channel/LIVE
- https://clientsettings.roblox.com/v2/client-version/MacPlayer/channel/LIVE
- https://clientsettings.roblox.com/v2/client-version/MacStudio/channel/LIVE

### Client Versions - ZBETA Channel
- https://clientsettings.roblox.com/v2/client-version/WindowsPlayer/channel/zbeta
- https://clientsettings.roblox.com/v2/client-version/WindowsStudio64/channel/zbeta
- https://clientsettings.roblox.com/v2/client-version/MacPlayer/channel/zbeta
- https://clientsettings.roblox.com/v2/client-version/MacStudio/channel/zbeta
